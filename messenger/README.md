# Chat Directory

Консольный прототип мессенджера. Многопользовательский чат с регистрацией, авторизацией, сохранением истории в файл и поиском сообщений.

## Основные функции

    Регистрация и вход с проверкой логина/пароля

    Отправка, просмотр, удаление и поиск сообщений

    Данные сохраняются в текстовых файлах
